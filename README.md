# 사진전시관 📸

사진작가를 위한 3D 전시 공간 — 폴더 하나를 열면 나만의 갤러리가 열립니다.

라이브: https://metasongi.github.io/photo-exhibition/

## 3D 전시관

- 🚶 워크스루: 드래그로 둘러보기, WASD/방향키 이동, 모바일 조이스틱, 벽 충돌
- 🖼️ 액자 배치 4종: 서펜타인 홀 · 아트리움 · 로툰다 · 미로
- 🎨 공간 디자인 19종
  - 기본: 화이트큐브 · 다크 무드 · 인더스트리얼 · 미니멀 화이트 · 선셋
  - 유명 갤러리 모티브: 루브르 클래식 · 구겐하임 · 테이트 모던 · 퐁피두 · 오르세 · 한옥 갤러리
  - 유럽·아시아 건축: 고딕 성당 · 바로크 궁전 · 지중해 · 젠 정원 · 자금성 · 북유럽
  - 트렌디: 네온 느와르 · 그레이지
  - 벽·바닥·천장에 재질 텍스처 적용, 궁전 테마는 기둥·금장식 건축 요소 포함
- 🔊 공간 사운드 4종 (갤러리 · 빗소리 · 바람 · 파도) — 공간 디자인에 자동 매칭, WebAudio 절차적 생성
- 🎧 도슨트 투어, 작품 클릭 확대 보기, ⛶ 전체화면
- 전시 중에는 상단 UI가 숨겨지고 3D가 화면을 가득 채움 (⌂ 시점 초기화, ☰ 메뉴로 가져오기·설정 접근)

## 사진 가져오기

- 📁 폴더 열기 / 💻 파일 올리기 / 🔗 링크 가져오기 / 📁 구글 드라이브 폴더 통째로
  - 드라이브 폴더는 Drive API 키(BYOK, 브라우저에만 저장), 하위 폴더 재귀 탐색
- 가져올 때 "기존에 추가" vs "다 지우고 새로 시작" 선택
- ✨ 데모 전시 (8점)

## 작가·전시 정보

- 🖋️ 전시 정보: 전시 제목 · 부제 · 작가명 · 작가 소개 · 연락처 → 3D 입구 안내판에 표시
- 📝 작품 제목·설명 편집 (작품 목록·라이트박스·3D 명판에 반영)
- ✨ AI 자동 설명 (Gemini BYOK)
- 📤📥 전시 공유: 전시 정보 → 내보내기로 JSON 파일 저장 (직접 올린 사진도 파일 안에 포함됨) → 파일을 전달받은 사람이 전시 정보 → 가져오기로 불러오면 동일한 전시가 열림

## 데이터 저장

모든 데이터(사진 목록·제목·설정)는 브라우저의 로컬 저장소(localStorage)에만 보관됩니다.
서버로 전송되지 않습니다. (직접 올린 파일의 blob URL은 새로고침 후 다시 올려야 합니다)
