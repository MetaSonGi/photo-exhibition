# 사진전시관

사진을 거는 다섯 개의 방 — 폴더 하나를 열면 전시회가 열립니다.

- 📁 폴더 열기 / 드래그앤드롭 / 데모 전시
- ⬜ 화이트큐브 — 미술관 화이트월에 액자 전시, 작품 캡션
- 🌑 다크룸 — 어둠 속 스포트라이트 전시
- 🚶 3D 전시관 — Three.js 워크스루 (WASD 이동·드래그 시점·도슨트 투어)
- 📽️ 프로젝터 — 풀스크린 상영회
- 📰 매거진 — 에디토리얼 지면 전시
- ✏️ 전시 제목·작품 캡션은 클릭해서 직접 수정 (브라우저에 저장)
